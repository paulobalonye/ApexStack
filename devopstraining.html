Welcome

What this program is

AI for DevOps is a live, mentor-led cohort that takes you from cloud fundamentals to advanced, AI-assisted DevOps on Microsoft Azure, all in 12 focused weeks. Every week pairs clear teaching with a real, hands-on lab, so you learn by building. You finish with a production-grade portfolio, a certificate, and guaranteed job-placement support.

Who it's for

Career-changers with no tech background, sysadmins and IT pros moving into the cloud, and developers or cloud engineers who want to add modern DevOps and AIOps to their toolkit. If you can use a computer and you're willing to practice, you belong here.

What you'll need

A laptop and internet connection, and roughly 10 to 15 hours per week. We guide you through setting up your Azure account (the free tier covers most labs). No prior cloud experience required.

🛠️

Tools you'll use

Microsoft Azure · Azure CLI · Terraform & Bicep · Docker · Kubernetes (AKS) · GitHub Actions · Azure Monitor · an AI coding assistant

🎯

Job placement, guaranteed

We support you until you're hired, with 1-on-1 mock interviews, resume & LinkedIn coaching, and direct employer connections.

The Curriculum

Weekly breakdown

Weeks 1 to 4

01

Week 1 · Cloud & Azure Foundations

Foundations
YOU'LL LEARN: How the cloud works; IaaS / PaaS / SaaS; the Azure portal, CLI & Cloud Shell; regions & resource groups; billing and cost controls.
YOU'LL BUILD: Set up and secure your own Azure account with budget alerts and your first resource.
02

Week 2 · Linux, Networking & the CLI

Foundations
YOU'LL LEARN: Linux essentials & SSH; networking basics (IP, DNS, ports, CIDR); automating tasks with Bash and the Azure CLI.
YOU'LL BUILD: Provision and configure a Linux VM with a repeatable script.
03

Week 3 · Compute, Storage & Networking

Foundations
YOU'LL LEARN: Azure VMs & scale sets; load balancing; Blob, Disk & File storage; Virtual Networks and subnets.
YOU'LL BUILD: Deploy an autoscaling web tier on a segmented network.
04

Week 4 · Identity, Access & Security

Core DevOps
YOU'LL LEARN: Microsoft Entra ID; role-based access control & least privilege; managed identities; Key Vault; encryption.
YOU'LL BUILD: Secure an app with least-privilege access and secrets stored in Key Vault.

Weeks 5 to 8

05

Week 5 · Infrastructure as Code

Core DevOps
YOU'LL LEARN: Terraform & Bicep; declarative infrastructure; state & remote backends; reusable modules; plan & apply.
YOU'LL BUILD: Recreate your entire environment as version-controlled code.
06

Week 6 · Containers & Docker

Core DevOps
YOU'LL LEARN: Containers vs VMs; Dockerfiles & multi-stage builds; Azure Container Registry; image scanning.
YOU'LL BUILD: Containerize an application and push a scanned image to ACR.
07

Week 7 · Azure Kubernetes Service (AKS)

Core DevOps
YOU'LL LEARN: Kubernetes core concepts; deployments, services & ingress; AKS; autoscaling and self-healing.
YOU'LL BUILD: Deploy and scale a multi-service application on AKS.
08

Week 8 · CI/CD & GitHub Actions

Core DevOps
YOU'LL LEARN: Pipelines (build, test, scan, deploy); GitOps; secure secretless authentication; progressive delivery.
YOU'LL BUILD: Build a pipeline that automatically deploys on every push.

Weeks 9 to 12

09

Week 9 · AIOps & Observability

AI & AIOps
YOU'LL LEARN: Metrics, logs & traces; Azure Monitor & Log Analytics (KQL); SLOs & alerting; incident response.
YOU'LL BUILD: Create a monitoring dashboard with alerts and an incident runbook.
10

Week 10 · AI-Assisted Engineering

AI & AIOps
YOU'LL LEARN: Using AI to generate & review infrastructure code, debug failures and draft runbooks, and learn how to verify it responsibly.
YOU'LL BUILD: Build an AI-assisted automation workflow you can fully explain and defend.
11

Week 11 · Serverless & Data Services

AI & AIOps
YOU'LL LEARN: Azure Functions & event-driven design; API Management; Azure SQL & Cosmos DB; caching & backups.
YOU'LL BUILD: Ship a serverless API backed by a managed database.
12

Week 12 · Capstone & Career Prep

Job-Ready
YOU'LL LEARN: Well-Architected review; cost optimization; portfolio polish; interview, resume & LinkedIn preparation.
YOU'LL BUILD: Complete your capstone project and finish job-ready with a portfolio and interview practice.
